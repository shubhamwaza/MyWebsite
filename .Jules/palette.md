## 2025-02-23 - Improve navigation accessibility
**Learning:** For dynamically injected menus (e.g. `mobileMenu` via JavaScript template literals), setting `aria-controls` on the toggle button explicitly connects the button to its target element in screen readers. Also, setting `aria-current="page"` statically on the `active` link enhances semantics compared to relying on CSS `.active` classes alone. We should also dynamically toggle `aria-expanded` attributes using `element.setAttribute()` on click to properly relay state to screen readers.
**Action:** Always include `aria-expanded`, `aria-controls`, and `aria-label` updates in the JavaScript functions that toggle mobile menu or modal states. Ensure `aria-current="page"` is evaluated and placed correctly when generating site navigation HTML templates.
