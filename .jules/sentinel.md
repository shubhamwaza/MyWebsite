## 2026-10-27 - [XSS via Attribute Injection despite textContent escaping]
**Vulnerability:** XSS vulnerability through attribute injection. The `escapeHtml` function used `div.textContent = str; return div.innerHTML;` which correctly escapes `<`, `>`, and `&`, but fails to escape single and double quotes (`'` and `"`). When this function is used to sanitize data placed inside HTML attributes (e.g., `alt="${escapeHtml(project.title)}"`), an attacker can break out of the attribute using quotes and inject malicious event handlers like `onerror` or `onmouseover`.
**Learning:** Browser DOM properties like `textContent` and `innerText` do not escape quotes when serialized back to `innerHTML`, as quotes are valid text content and not strictly structural to HTML text nodes (unlike `<`, `>`, and `&`).
**Prevention:** Always escape quotes explicitly (e.g., replace `"` with `&quot;` and `'` with `&#39;`) when creating a general-purpose HTML escaping function, especially if its output will be interpolated into HTML attributes.
