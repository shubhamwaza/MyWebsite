## 2024-03-24 - [Fix XSS vulnerability in escapeHtml]
**Vulnerability:** Using DOM text node assignment (`document.createElement('div').textContent = str; return div.innerHTML`) for escaping HTML strings fails to encode single and double quotes, leaving the application vulnerable to attribute injection XSS.
**Learning:** This vulnerability existed because the previous developer attempted a clever, DOM-based approach for escaping HTML characters. However, setting `textContent` and retrieving `innerHTML` only escapes `<`, `>`, and `&`, meaning that any attributes dynamically generated with the `escapeHtml` function (like in `<img alt="${escapeHtml(post.title)}">`) can be broken out of if `post.title` contains a quote (e.g., `"" onerror=alert(1)`).
**Prevention:** Always use a comprehensive, regex-based escaping function that replaces `&`, `<`, `>`, `"`, and `'` with their respective HTML entities (`&amp;`, `&lt;`, `&gt;`, `&quot;`, `&#39;`). Do not rely on browser DOM manipulation hacks for security-critical escaping logic.
