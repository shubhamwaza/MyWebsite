## 2024-03-24 - Avoiding Layout Thrashing in Interactive Hover Effects
**Learning:** High-frequency events (like `mousemove` and `pointermove`) cause severe layout thrashing when calling `getBoundingClientRect()` repeatedly on every frame. When caching the rect for elements that may have active CSS transforms (like `.magnetic` which uses `transform: translate(...)`), the transform must be temporarily set to "none" before measurement to get an accurate, un-transformed bounding box, then restored.
**Action:** Always cache bounding box measurements for high-frequency event listeners by storing them directly on the target element (e.g., `el._magneticRect`), calculate them on-demand if null, and invalidate the cache using a single global passive `scroll` and `resize` listener outside the event loop, rather than recalculating on every move event.
