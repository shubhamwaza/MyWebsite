## 2024-11-01 - Pair visual state classes with ARIA attributes
**Learning:** When using classes like `.active` to indicate state, it's crucial to pair them with appropriate ARIA attributes (`aria-current="page"` for nav links, `aria-pressed="true"` for filter buttons) to ensure screen reader users receive the same state information.
**Action:** Always add semantic ARIA attributes alongside visual state classes for interactive elements.
