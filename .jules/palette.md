## 2026-08-09 - Accessible Navigation Patterns in JS-Driven Menus
**Learning:** In purely vanilla JS-driven websites without frameworks, dynamic UI states like mobile menus often lack accessible attributes by default. Ensuring ARIA states (`aria-expanded`, `aria-label`) are toggled simultaneously with CSS classes is crucial for screen readers, as well as statically setting `aria-controls`. Also, `aria-current="page"` needs dynamic assignment since nav link states are rendered dynamically via JavaScript based on the current page's URL.
**Action:** When implementing or updating JS-rendered navigation systems, ensure any UI-toggling JavaScript simultaneously updates corresponding ARIA attributes, and assign `aria-current="page"` explicitly to active navigational elements rather than just relying on active CSS classes.
