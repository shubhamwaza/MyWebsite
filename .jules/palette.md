## 2024-05-24 - Dynamic ARIA attributes in Vanilla JS menus
**Learning:** When implementing or updating JS-rendered dynamic UI components (like navigation menus), ensure that ARIA attributes (e.g., `aria-expanded`, `aria-label`, `aria-controls`, `aria-current`) are toggled simultaneously with CSS classes or states in the JavaScript logic.
**Action:** Always verify that state changes (like opening a menu) update both visual classes and accessibility attributes together.
