## 2024-05-14 - Navigation Menu ARIA Accessibility
**Learning:** In vanilla JS UI components like navigation menus, ARIA attributes (e.g., `aria-expanded`, `aria-label`, `aria-controls`, `aria-current`) must be toggled simultaneously with CSS classes or states in the JavaScript logic.
**Action:** When creating or fixing interactive components like mobile menus, ensure they are paired with ARIA roles and dynamically updated states to maintain screen reader accessibility.
