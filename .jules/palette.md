## 2026-10-26 - Add simulated async loading state to static contact form
**Learning:** In a zero-dependency static prototype, simulating network latency (e.g., on form submission) with visual loading states is critical because immediate transitions break the illusion of reality and deprive users of reassuring feedback.
**Action:** Always include disabled button states and loading spinners for simulated forms in static prototypes to mirror real-world UX.
