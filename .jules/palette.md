## 2023-10-27 - Mobile Menu Accessibility Enhancements\n**Learning:** The mobile menu toggle lacked `aria-expanded` and the toggle text/icons were swapping without updating `aria-label`, leaving screen reader users unaware of the menu state. Updating `aria-expanded` on toggle ensures screen readers announce the state change properly.\n**Action:** Add `aria-expanded="false"` by default to navigation toggle buttons, and dynamically update it to `"true"` when toggling the menu state open.
