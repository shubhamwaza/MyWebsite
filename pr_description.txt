💡 What: Added an `isLooping` state and a threshold check to the cursor-follow image preview animation loop (`initCursorPreview`) in `js/main.js`. This pauses the `requestAnimationFrame` loop when the cursor reaches its target position, and safely restarts it on the next `mousemove` event.
🎯 Why: Continuous `requestAnimationFrame` loops run indefinitely by default, even when the visual target is reached and the animation is idle. This consumes CPU resources and drains battery unnecessarily, especially on a portfolio site where users might leave the page open in the background.
📊 Impact: Reduces idle CPU usage for the cursor preview component to 0% when the mouse is not moving, without affecting the smooth easing animation during movement.
🔬 Measurement: Verify by interacting with the project rows on the Work page. The cursor preview should follow the mouse smoothly. When the mouse stops, the continuous loop will pause. This was verified locally using a Playwright script that intercepted `requestAnimationFrame` calls and counted frame execution during active and idle states.
